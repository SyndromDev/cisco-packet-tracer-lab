# Lab 3 - DHCP Network Configuration

## Цель
Настроить маршрутизатор в качестве DHCP-сервера для автоматического назначения IP-адресов устройствам в двух разных локальных сетях.

--

## Используемые технологии
- Cisco Packet Tracer
- DHCP
- IPv4
- Маршрутизатор
- Коммутатор
- ICMP (Ping)
