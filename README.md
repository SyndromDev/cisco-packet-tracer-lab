## Лабораторная работа 1: Базовая локальная сеть

### Цель
Настроить простую локальную сеть и проверить подключение с помощью ICMP (ping).

### Топология
- 2 ПК
- 1 коммутатор
- Сеть: 192.168.1.0/24

### Конфигурация IP-адресов
PC0: 192.168.1.1
PC1: 192.168.1.2

### Проверка
- Успешное подключение между хостами (ping)
- Зеленый статус соединения в Packet Tracer
